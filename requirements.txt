# A note on memory
# ---------------------------------------------------------------------------
# The training pipeline was developed and verified on a 2 GB box. `build_dataset` computes
# weak labels for all 8.76M edge-days first (~35 MB) and only then materialises features for
# the down-sampled rows (~65 MB), because a dense 8.76M x 14 matrix plus gradient boosting
# got the process OOM-killed at 1.55 GB RSS. If you raise SAMPLE_EDGES or NEG_PER_POS on a
# small machine, watch RSS - the kernel kills it silently and a piped `tee` still exits 0.
